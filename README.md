# Inventory Management System

## Description
A simple Inventory Management System developed using Python Tkinter and SQLite.

## Features
- Add Product
- Update Product
- Delete Product
- Search Product
- View Products
- SQLite Database

## Technologies Used
- Python
- Tkinter
- SQLite
